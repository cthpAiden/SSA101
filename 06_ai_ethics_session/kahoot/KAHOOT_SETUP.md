# Kahoot setup: G1 Help Not Hinder quiz review

File: `G1_Kahoot_Quiz.xlsx` (15 questions, 4 answers each, 20 s each). Questions 1 to 10 come from the slide 15 speaker notes in Canva; 11 to 15 are new scenarios that apply the lesson; fill-in-the-blank and open questions became 4-option multiple choice.

## Build (about 5 minutes)

1. Log in at create.kahoot.it (Trúc's account, since Trúc hosts the quiz).
2. Create > Kahoot > blank quiz.
3. Add question > Import spreadsheet > drop `G1_Kahoot_Quiz.xlsx` > Import.
4. If Kahoot rejects the file: download its own template from the same dialog, copy cells B9:H23 from our file into the same cells of the template, and import that.
5. Delete the empty default question 1 if it is still there.
6. Title: "G1 Help Not Hinder: Quiz Review". Save.
7. Test once with a phone as a player.

## In class (slide 15, 72:00 to 80:00)

1. Open the kahoot > Start > Classic mode.
2. Show the PIN screen; students join at kahoot.it.
3. Ask students to use their team name (row of desks) in the nickname, so team scores can be added to the game totals.
4. 15 questions x about 45 s (answer + leaderboard) = about 11 minutes, 3 more than the 8-minute block.
